# 数据目录

这是考研学习空间的唯一外部数据目录，和 `src/`、`electron/`、`dist/` 等应用文件分开。

```text
数据/
├── 默认题库/
│   ├── 题库数据.json
│   ├── 数学/
│   ├── 英语/
│   └── 专业课/
└── 用户数据/
    ├── 用户数据.json
    └── 用户笔记/
        └── 题库编码/章节编码.json
```

网页版首次使用时，选择本目录 `数据/`，应用会同时读取同级的 `默认题库/` 和 `用户数据/`。Electron 版会优先查找应用旁边或当前工作目录的 `数据/`，找不到时使用系统文档目录下的 `考研学习空间/数据/`。

题库清单和题目图片只放在 `默认题库/`；学习标记、每日记录、错误记录、设置和笔记只放在 `用户数据/`。不再从旧目录读取或写回数据。
